# Kaiqi Zhang — GitHub Pages Website

## Folder structure

```text
kaiqi-zhang.github.io/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── profile.jpg
│   └── Kaiqi_Zhang_CV.pdf
└── README.md
```

## Deploy

1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload all files and the `assets` folder.
3. Rename/add your own files:
   - `assets/profile.jpg` — your portrait
   - `assets/Kaiqi_Zhang_CV.pdf` — your CV
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch → main → / (root)**.
6. Open `https://YOUR_USERNAME.github.io/`.

## Customize

Search these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- DOI links (`href="#"`)
- Google Scholar / ORCID / LinkedIn links
- publication metadata

The Chinese/English switch is handled by `script.js`.
